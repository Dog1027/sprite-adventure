# 美術待辦

精靈動畫與場景背景目前都是 `tools/` 的腳本產生的**占位圖**。圖的規格（大小、排法、哪些區域要暗）見 [ARCHITECTURE.md](ARCHITECTURE.md) 的「精靈動畫圖」「場景背景」。

這份文件記錄還可以加強的地方；做完的項目請直接刪掉或打勾。

## 正式美術

- [ ] 12 種精靈的正式動畫圖：照現在的排法畫好，蓋掉 `assets/sprites/<代號>.png`
- [ ] 8 個場景的正式背景：照 225×400 畫好，蓋掉 `assets/scenes/<場景>.png`
- [ ] 換成正式美術後，`tools/` 的占位圖腳本就不要再執行，以免把正式的圖蓋掉

## 場景

- [ ] 場景小動畫：營火閃爍、草隨風擺動、飄霧、星星閃爍
  - 做法構想：背景維持一張靜態圖，動的部分另外畫成小圖疊在上面，由 `art.rs` 依時間播放
- [ ] 菁英戰、頭目戰換成專屬的戰鬥場景（目前所有戰鬥共用 `battle`）
- [ ] 更多戰鬥場景的變化，例如依地圖階段換成森林深處、洞穴

## 精靈與畫面

- [ ] 捕捉畫面、休息畫面加上精靈的待機動畫（目前只有文字）
- [ ] 擺位時拖曳中的精靈改成角色圖（目前還是卡片）
- [ ] 戰鬥中名牌的名字和血條用 12px 字，手機上可能偏小，要實機確認
- [ ] 精靈腳下的名牌可能被前排的角色擋住一部分，必要時把名牌改成最後一起畫
